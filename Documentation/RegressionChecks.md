# Проверки после аудита

Запуск всего набора:

```sh
bash Scripts/check.sh
```

Команда выполняет проверки ядра, регрессии аудита, проверку нативного меню и typecheck приложения и WidgetKit extension. Нужен macOS SDK 26+, выбранный через `Scripts/toolchain.sh`. Изолированная проверка интерфейсного кода — `bash Scripts/check-ui.sh`.

`LLMUsage/Tests/RegressionScenarios.swift` и `LLMUsage/Tests/PricingScenarios.swift` содержат именованные сценарии. Один и тот же код выполняется portable harness и XCTest (`RegressionTests`, `PricingTests`), включая `swift test` и тестовый target Xcode. При добавлении проверки не нужно копировать её в два набора.

| Область | Защищённое поведение |
| --- | --- |
| Формат сумм | Знак доллара сохраняется при исключениях и отсутствии тарифов, включая нулевые и сокращённые суммы на двух языках. Знак ≥ не добавляется. |
| Исключение моделей | Правила по точному имени и Z.ai / GLM по умолчанию исключают токены и стоимость. Проверяются смешанные сессии, обратное включение, история, старый кэш, виджеты, перезапуск и изменение правила во время запроса. |
| Справочные значения моделей (#11) | Только вкладка «Модели» показывает исходные суммы и все категории токенов исключённых моделей. Проверяются ручные исключения и GLM по умолчанию, сортировка по исходной стоимости, фильтр источника, выбранная дата, восстановление из JSON, повторное включение, неполные тарифы, полностью исключённый день и смешанные сессии без двойного учёта. Общие итоги остаются с исключениями. |
| Способ обновления | По умолчанию выполняется только команда Claude. Для всех агентов выполняются две команды с точными границами дня; Claude-строки заменяются, остальные источники сохраняются. Проверяются пустые отчёты, ошибки каждой команды, постоянство ID, сохранение настройки, совместимость кэша, история и смена режима во время запроса. |
| Кэш тарифов Claude (#10) | Ставки переживают перезапуск и отсутствие сети, обновляются после нового ответа и HTTP 304. Ошибочные ответы не стирают сохранённые цены. Проверяются отсутствующий/повреждённый кэш, удалённые из каталога модели, общий запрос при конкуренции, приоритет пользовательского конфига и удаление временного конфига после успеха/ошибки CLI. |
| Исходные записи чата | События разделяют неизменяемую запись. Экспорт включает её один раз; тесты на 1, 20 и 80 параллельных инструментах проверяют линейный рост, сопоставление результатов и сохранение метаданных. |
| Два потока Codex | Дедупликация использует текст сообщения, а не локализованное описание вложения. Проверяются оба порядка записей, оба языка, повторные запросы и сообщения только с изображением. |
| Время в чате (#20) | `TranscriptTimingScenarios` выполняется в portable harness и XCTest. Проверяются отдельные интервалы сообщений и инструментов, TTFT на уровне запроса, скорость по токенам того же turn, поздние завершения, прерывания, неполные данные, параллельные вызовы, одинаковые ID в разных журналах, неоднозначные ID, Claude `end_turn`/`turn_duration`, Gemini inline results, невалидные числа и единицы времени, переход через полночь, экспорт, повторный разбор и отсутствие изменений биллинга. |
| Поиск файлов | JSON, JSONL и NDJSON находятся по точному ID в заголовке, даже когда имя отличается. Текст сообщения не принимается за ID. |
| Поиск в интерфейсе | Работа выполняется вне главного потока. Новый запрос отменяет старый; запоздалый результат не публикуется. Проверяется восстановление после отмены, поиск по всем полям, группировка контекста, сортировка и согласованность итогов. |
| Исторический кэш | Единая политика срока жизни для выбранного дня и недельной истории. Ручное обновление запрашивает выбранный день заново; завершённые дни истекают через шесть часов, включая даты старше недели. Неполный день и будущий timestamp не считаются свежими. |
| Смена дня | При ошибке сохраняется последняя успешная сумма, а подпись показывает фактическую дату снимка. Проверяются полночь, оба языка и календарные границы DST. |
| Ссылки виджетов | День и timezone проходят полный URL round-trip вместе с непрозрачным ID. Холодное открытие загружает нужный снимок и сохраняет выбор сессии. Старые ссылки поддерживаются, некорректные даты и параметры отклоняются. |

Быстродействие защищено проверками структуры и поведения, а не хрупкими порогами миллисекунд: отсутствие копий больших исходных записей, линейный размер экспорта, фоновые вычисления и отклонение устаревших результатов. Эти проверки не заменяют ручную проверку размещённого системного виджета.

`bash Scripts/check.sh --live-cli` дополнительно проверяет установленный ccusage на синтетических Claude-журналах в отдельном временном каталоге. Сетевой сбой задаётся только дочернему CLI через proxy-переменные; сеть macOS и пользовательские журналы не изменяются. Проверяются неизменность стоимости после перезапуска без сети, рост суммы при добавлении токенов, ставки длинного контекста, Fast mode и часового cache write. Затем сохранённый публичный тариф для Claude Sonnet 4.6/5.5 сравнивается с обычным онлайн-отчётом ccusage. Сам кэш проверяется без сети в обычном наборе; live-проверке нужен доступ к каталогу LiteLLM.

`bash Scripts/check-windows.sh` проверяет реальные границы нативных колонок, прокручиваемых областей и поиска при повторном сужении всех вкладок до 860 точек на русском и английском, ограничения ширины окна с открытым инспектором и после его закрытия, а также неподвижность привязки меню при обновлении данных и применение свежего значка после закрытия. Проверки выполняются в отдельном процессе с демо-данными.

`bash Scripts/render-previews.sh --models --language=ru` (или `--language=en`) создаёт превью вкладки «Модели» с исключённой моделью на светлой и тёмной теме, при ширине содержимого 610 и 880 точек. Проверяются исходные токены/стоимость, пометка исключения, отсутствие полосы доли расходов у исключённой строки и заголовок учтённой суммы.

Для боковой панели проверяются синхронизация выбора раздела, переходы стрелками и сохранение нейтрального выделения после смены вкладок и размеров окна. Проверка отрисованных пикселей охватывает светлую/тёмную тему и активное/неактивное состояние: фон выделения нейтральный, текст и иконка используют акцент только в активном окне.

`bash Scripts/render-previews.sh --sidebars --language=ru` сохраняет в `build/Previews/localization-ru` восемь превью боковой панели, включая выбранные «Настройки». Это превью содержимого на однотонной подложке: системное стекло `NavigationSplitView` и его прозрачность нужно смотреть в окне приложения. При ручной проверке переключите фокус на другое окно, проверьте обе темы, фильтры источников, увеличение контраста и уменьшение прозрачности в настройках macOS.
